# EpicSlice

Skill de Cursor que transforma PRDs, Épicos e Iniciativas em User Stories acionáveis, cruzando **Jobs to be Done (JTBD / Ulwick)** com **Product Backlog Building (PBB / Caroli & Aguiar)**.

## Conteúdo

```text
epic-slice/
├── SKILL.md      # System prompt / instruções da skill
└── reference.md  # Referência rápida JTBD × PBB
```

## Como usar no Cursor

1. Instale/copie a pasta `epic-slice` para suas skills (Agent Store ou `.cursor/skills/`).
2. Invoque com `@epic-slice` e envie um PRD, Épico ou Iniciativa.
3. A skill devolve: resumo JTBD, árvore PBB, User Stories com BDD e backlog ordenado.

## Fontes conceituais

- Anthony W. Ulwick — *Jobs to be Done: Theory to Practice*
- Paulo Caroli & Fabio Aguiar — *Product Backlog Building*

A skill sintetiza princípios; não reproduz o texto dos livros.
